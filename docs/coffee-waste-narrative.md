# Coffee waste — project narrative & Melbourne context

## Core interest (your words, refined)

> Reimagining coffee waste is not just about diverting landfill — it is about making waste **alive** again, so it **serves a civic purpose** in the city.

This experiment investigates how **spent coffee grounds** can be **reproduced as functional architecture** — starting at the scale of:

- Coffee shop **furniture**
- **Shelter** / temporary canopy
- **Event architectural elements** — ornament, facade, pavilion fragments

**Position:** Coffee in Melbourne is culture, ritual, and identity. The grounds are not “rubbish” — they are a **latent building material** waiting for architectural authorship.

## Architectural position (coffee-specific)

**Against:** Coffee waste as guilt-driven sustainability checkbox or landfill diversion statistic alone.

**For:** Coffee grounds as **Melbourne’s latent tectonic material** — smell, texture, colour, and cultural memory embedded in **civic architecture** that cafés and neighbourhoods can recognise.

**Critical line for panel:**  
*“The grounds already serve Melbourne socially — in the cup. This project asks what happens when they serve Melbourne **spatially**.”*
